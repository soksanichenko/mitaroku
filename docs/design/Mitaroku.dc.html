Design notes (not part of the UI)
Navigation. From 720 px the header holds the logo, Library, Upcoming, the search field, the notifications bell with its unread counter, the theme toggle and the user menu (Profile & settings, Import / export, EN / RU, Log out). Below 720 px the header shrinks to the logo, a search icon and the theme toggle, and a fixed 56 px bottom tab bar holds Library, Upcoming, Search, Notifications and Profile. Pages get 72 px of bottom padding so the bar never covers content. Detail, Browse and Collection pages count as Library in the navigation.
Screens and routes. Each screen is its own component under one shell, and the address is the state: #/library, #/upcoming, #/search?q=, #/notifications, #/settings, #/import, #/export, #/login, #/title/show|anime|movie, #/browse?type=&genre=&country=&year= and #/collection/<id>. Each maps one-to-one to a Django view, with HTMX swaps for filters, Load more and status changes.
Loading, empty and error. Every screen has all three. Preview them with Tweaks → Demo state; “Try again” goes from error to loading to the live view. Search also has a typing hint (one character), no results (try “zzz”) and a provider error (search for “error”). Skeletons copy the final layout so nothing jumps when content arrives.
Shared components. Rating badge (source + value, tooltip “TMDB user score, out of 10”, accessible name; MAL on anime). Status picker: an ink chip with the current status, or an outlined “Add”; both open the same menu (Watching, Plan to watch, Completed, Dropped, Remove), with 44 px rows. Poster card: poster, rating badge, airing chip, title, year and the status picker; the Library variant adds the 3 px progress bar and the next air date. Round check: the same three-state control as the episode list.
Browse and Collections. Every “See also” link opens Browse with its filters already in the address, and the page title is generated from those filters (“Drama series of 2025”). Removing a chip or adding a filter rewrites the address, so Back and shared links work. Collection cards open the collection page; the counts on the cards come from the collection’s own titles, so the card and the page always agree.
Red on text surfaces. The bell counter, unread dot, TODAY tags, field errors and primary buttons (Continue, Search, Start import, Download, Sign in, Mark all as watched) all use accent-700 with light text: 6.6:1. Statuses everywhere else are ink chips, so red stays reserved for actions and new or urgent state.
44 px touch targets. Every control is at least 44 × 44 px: the header theme toggle, bell and avatar, the detail-page section tabs (Description, Cast, Episodes, Similar, More), franchise and filter chips, status pickers, check buttons and bottom tabs. Icons stay at 18–22 px inside the larger hit area, so the header is still 56 px tall. On Library and Browse cards, the poster and the title block form one link, and the title block is at least 44 px tall.
Telegram states. Not connected (Connect Telegram) → Waiting (one-time link to the bot, 10-minute countdown, Cancel) → Connected (“Connected as @kira_mori”, Disconnect with a confirmation step). Blocked: if the user blocks the bot, the block shows “Telegram notifications are off: the bot was blocked” with Reconnect, which starts a new one-time link. Preview each state with Tweaks → Telegram state; while Waiting, the Tweaks control “Simulate Start in Telegram” stands in for the bot callback and moves the block to Connected.
Languages. The EN / RU switch in the user menu and the Interface language setting share one value. In this prototype it translates the global navigation; screen copy is English placeholder. Metadata language is a separate setting and controls titles and descriptions from TMDB and MyAnimeList.
Prototype data. All screens read one in-memory store, so a status set in Search, Browse or a collection shows up in Library and Upcoming straight away. The demo date is Oct 8, 2026. Titles without their own placeholder page open the nearest of the three detail pages (show, anime or movie). The store resets on reload.
Detail pages
Red accent. Only for user actions and state: the active watch status, the Continue button, Save, the TODAY tag and focus rings. Every red surface that carries text uses the deep step --color-accent-700 (#AE1800) with light text --color-neutral-100 (#F8F4F4), in both themes: 6.6:1, against the 4.5:1 target for text under 24 px. Hover and pressed states go one step deeper (accent-800 #7C1405 at 9.9:1, accent-900 at about 14:1). The brighter accent (#EC3013 light, #FF563C dark) is kept only for text-free signals such as the focus ring; it measured 3.85:1 and 2.89:1 with light text. In the dark theme the active segment also gets a bold label and a check icon (from 480 px), so the filled state does not rely on color alone. External ratings are neutral ink blocks that name their source (TMDB user score for shows and films, MAL for anime). Each title carries one field, a source name plus a value, so another source such as IMDb can be added later without changing the layout. The badge has a tooltip (“TMDB user score, out of 10”) and an accessible name. Bullets, the nav underline and rating badges are ink.
Imagery. Grayscale by default (the system’s .grayscale filter). An image switches to color (1) on hover or keyboard focus, and (2) when it is the active item: this page’s own backdrop or poster, and the selected trailer. Lists (Similar, Collections, trailer thumbnails, cast photos) stay grayscale until hovered or focused. Placeholders are tinted so you can see the switch.
Secondary text. Ink at 72% opacity, applied to labels, dates, hints and counters: about 6:1 on the light ground. The dark theme keeps the same targets: secondary text about 8:1, body text about 15:1 and blue links about 9:1 on the dark ground. Watched episode titles switch from blue to muted ink at full opacity; they are never faded.
Breakpoints. Below 480 px: no wordmark, short status labels, no check icon in the status control, and movie facts stacked. From 600 px: each episode row is one grid (number, title, date, stars, menu, check) across the full content width. The title column is capped at 420 px so the date and stars stay close to it. From 720 px: two-column hero (image left; status, rating and facts right; poster at most 240 px). Cast shows 2, 3 or 4 columns below 600 px, from 600 px and from 840 px.
Episodes. Fully watched groups start collapsed, and the group with the next episode stays open. Single-entry groups (for example one movie) render as one row with a type tag. Continuation groups show the absolute number beside the season code (for example “7 · S2E1”); Tweaks can switch to per-season only or continuous only. The number column fits 4 digits. The “Mark all up to here” hint shows once, after your first check, and stays dismissed.
