{% comment %} The episode list of a series or an anime franchise. Alpine keeps the open accordion groups; the franchise chips open a group and scroll to it. Context: groups (GroupView list), multi (more than one group), open_ids (groups that start open), chips (groups again for anime with several entries, else empty), entry, progress, has_views (the user has a viewing of the title: the bar shows without an entry), whole, has_rows, next_row (see _title_progress.html and _continue_bar.html); oob (optional): send it as an out-of-band swap of #episodes. It holds #title-progress, #continue-bar and #mark-up-to-hint, so a response with the section sends none of them separately. A collapsed group with many rows is lazy (see _episode_group.html): opening it (toggle, or a chip through show) calls load, which fires the htmx request for its rows only while the container still has data-lazy. A chip scrolls to the group at once and again when its rows arrive (jumpTo), since the page grows then. The Alpine scope also keeps the open row menu (menu), the long press and the control that gets the focus once a menu action has been swapped in (focusAfter). {% endcomment %}{% load i18n web_extras %}
