{% comment %} The one-time tip about "Mark all up to here as watched": div#mark-up-to-hint. It is always on the page; a single-episode mark sends it out of band with armed true. Whether it shows is decided by CSS from two things that survive an HTMX swap: its data-armed attribute (from the server) and data-hint-mark-up-to="dismissed" on (hint.js, from localStorage or a dismissal in this page). Dismissing it, or using the action (the window event mt-up-to), calls mtDismissMarkUpToHint(). No state is kept on the element: an out-of-band swap re-creates it and resets its attributes after Alpine has started. Context: armed (bool); oob (optional): add hx-swap-oob="true". {% endcomment %}{% load i18n %}
